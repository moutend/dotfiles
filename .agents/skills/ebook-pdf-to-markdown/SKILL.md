# PDFファイルをMarkdownファイルに変換する手順

1. 対象のPDFファイルについて、その名前から拡張子を除去した名前でディレクトリを作ります。
  - 例えば`データベース入門.pdf`ならば、同じディレクトリ階層に`データベース入門/`ディレクトリを作成します。
  - すでに同名のディレクトリが存在する場合は作業を中止して、その後の対応方針をユーザーに確認してください。
2. 手順1で作成したディレクトリの中に、チャプター単位でMarkdownファイルを作成します。
  - 例えば`データベース入門/intro.md`, `データベース入門/author.md`, `データベース入門/chapter01.md`, `データベース入門/chapter02.md`, ...のように、チャプター単位で個別にMarkdownファイルを作成します。
  - 書籍の名前に関係なく、Markdownファイルの名前は英語小文字で記入してください。またチャプター番号のような連番をファイルに含める場合は、番号をゼロで埋めてください。
  - ファイル名に使える文字はASCIIの英語小文字と数字、記号は`_`のみとします。
  - 目次と索引については作成いただく必要はありません。
  - PDFファイルの読み取りは1ページ目から最後のページに向かって行います。ランダムにページを開いて並列に変換作業を行わないでください。
3. PDFファイルに画像が含まれている場合、手順1で作成したディレクトリの中に`images/`ディレクトリを作成して、そこへ配置します。
  - `データベース入門/images/intro_1.jpg`, `データベース入門/images/intro_2.jpg`, ...のように、その画像が配置されているチャプターに対応するファイル名で画像を配置してください。
  - Markdownファイルから画像を参照する場合はファイルパスとして`/images/intro_1.jpg`のように、`/images`からのパスで示してください。
  - ターミナルでのCLI操作を撮影した画像のように、画像の内容をテキストとして抽出可能な場合は、画像化せずにテキストで表現してください。
  - PDFファイルには、特に意味のない装飾目的の図形やイラストが含まれているかもしれません。そういった図形やイラストは無視してください。
# Markdownシンタックスの注意点

## 見出し

見出しは必ず`#`記号で表現してください。見出しレベル1はチャプターの名前、見出しレベル2以上はセクションの名前に割り当ててください。

例:

```markdown
# 第1章 リレーショナルデータベースの歴史

## 1.1 コンピューターが登場する以前

### コラム: 洞窟に刻まれたデータベース

## 1.2 初期の試み

### 1.2.1 表計算
```

## 強調表現

- Markdown書式の`**`による太字強調は利用を避けてください。
- ページのレイアウトから、見出しテキストであると判断できる場合には`#`記号を使って、適切なレベルで見出しとして表現してください。

## 箇条書き

番号なしの箇条書き表現には`-`記号を利用してください。

## コードブロック

コードブロックはフェンス形式で表現してください。

## 数式

- 数式はLaTeX形式で記述してください。演算子やLaTeXコマンドの前後には、必要に応じて空白（` `）を追加し、テキストとして読みやすくなるように心がけてください。
- 簡単な数式だとしてもプレーンテキストやUnicodeの数式記号だけで表現することは避けてください。
- 数式ではなく数値を示す場合はASCIIのプレーンテキストを利用して構いません。例えば、1.23 kgや456 Hzなど。
- 本文中のインライン数式は`$`で囲み、独立した数式のブロックはMarkdownのフェンス形式を使います。

例:

```math
f(x) = \frac{1}{x} + 2
```

## 脚注

脚注は次の書式で記入します。

```markdown
本書で紹介するソースコードについてはGitHubリポジトリ[^1]で公開しています。また正誤表については本書のサポートページ[^2]にて公開しています。

[^1]: https://github.com/foo/bar
[^2]: 諸事情により出版社のホームページが閉鎖されたため、現在はGitHubリポジトリにて公開しています。
```

本文中では`[^脚注番号]`で記入し、詳細情報については独立した行で、`[^脚注番号]: `に続けて脚注の詳細を記入します。

## 日本語の表現

- 日本語の文章中では、かっこの記号として`（）`を使ってください。
- ASCIIテキストとUnicodeテキストの教会に空白を含めないでください。
  - 悪い例: `コンソールに「 Hello, World! 」と入力してください。`
  - 良い例: `コンソールに「Hello, World!」と入力してください。`
