# Repository Instructions

## Git Workflow

- Before editing, run `git status --short --branch`.
- Treat existing uncommitted changes as user-owned. Do not modify, delete, or stage them unless explicitly asked.
- Split work into small logical commits.
- After each complete unit, stage only the relevant files, run the appropriate validation, and commit.
- Do not commit broken, partial, or unverified states.
- Use Conventional Commits for commit messages.
- At the end, report created commits, validation performed, and remaining uncommitted changes.
